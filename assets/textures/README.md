# Photo textures

`hardwood2_*` — plank floor (color, bump and roughness maps) from the three.js examples
(`examples/textures/hardwood2_*.jpg`, three.js is MIT-licensed). The `_s` files are half-size copies
for phones and tablets. Everything else in the museum is generated in `js/textures.js`.

`head-scan-normal.jpg` — fine skin detail for the statue's face, part of "Infinite, 3D Head Scan" by
Lee Perry-Smith (CC BY 3.0, see `tools/statue/head-scan/LICENSE.txt`).
